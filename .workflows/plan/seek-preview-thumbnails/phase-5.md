```markdown
### Seek previews

![The pointer on the timeline: the frame at 0:40 from the stream's own preview track, and the time under it](img/streaming/player-preview.png)

With the pointer on the player's timeline, a box above it shows the time at that point and, where
the session has one, the frame of the film there: a picture 240 px wide, taken within 10 seconds of
that time. Where the session has no frame for that point, or its picture does not load, the box
shows the time alone, never a broken picture. The box follows a drag of the position too, goes when
the pointer leaves the timeline or the controls hide, and never takes a click.

The frames come from the first of three sources that has any for the session:

1. **The stream's own preview track.** Many players load a WebVTT file whose cues are pictures,
   each a part of a larger sheet (`thumbs/sprite-001.jpg#xywh=160,0,160,90`, see "Where subtitles
   are found"). The resolver keeps the first one the page loaded as the source's `thumbnails`, with
   the headers of that request. The daemon reads it once per session through the same headers, with
   a size limit and a time limit, and lists a frame per cue. The page fetches each picture through
   the pass-through (`img=1`), which asks only the hosts the track named, takes only an `image/*`
   answer under a size limit, and records it in the stream evidence as `image`, never as part of the
   provider's delivery. A track that cannot be read, is too large or names no picture gives no
   frame. It covers the whole film at once, so it is asked first.
2. **A torrent's video on this machine:** the file as it downloads, or its remux.
3. **The stream cache the session plays from**, ready or still downloading. A session that streams a title through
   a provider gets no frame from a cache of that title on this machine: that copy may come from another provider
   whose timeline is slightly offset.

For the last two the daemon makes the frames itself, with ffmpeg, from the video on disk:

- **Sheets.** A frame every 10 seconds, 240 px wide, up to 36 frames (6 minutes of film) to one
  JPEG. A sheet is made only once its whole stretch is on disk, so the frames grow sheet by sheet
  with the download (on a torrent, with the grey bar), and the film has all its frames when its last
  sheet is made.
- **One at a time, out of the way.** One preview ffmpeg runs at a time for the whole daemon, at low
  CPU priority, the film on screen first. A whole cache or a whole torrent download that nobody plays
  gets its sheets in the background too, so an episode fetched ahead has its frames before it plays.
- **Only what is on disk.** A cache is read from its files. A torrent's file that is still
  downloading is read only where its pieces are on disk: a sheet that would need a missing piece
  stops and is tried once more of the file is there. For a frame the torrent is never held in the
  swarm, no file is selected and no piece is asked for. No preview build makes a network request.
- **A failure is a missing picture.** A sheet is written to a temporary name and renamed when it
  is whole. ffmpeg that is missing, fails or runs past its time limit leaves nothing, and the sheet is
  tried again a fixed number of times, then left. Each failure is one line in the daemon's log; the
  play, its manifest and the download are never touched.
- **Kept.** Finished sheets stay beside the video and survive a restart; after one, only the
  missing sheets are made.

The sheets of a cloud cache are in its folder, `<cache id>/previews/`; those of a torrent's file or
its remux in `<NOTESD_TORRENT_DIR>/<info hash>/notesd-previews/<file index>/`. They count in the
size on disk of their cache or download (the torrent budget, the
[Cache page](movies.md#the-cache-page)) and go with it: a cache cleared, a download deleted whole or
one episode of a season pack deleted takes its sheets along.

What is not done: a cloud stream with no preview track and no cache on this machine gets no frames,
since making them would mean hundreds of requests to the stream host for one film; the box shows the
time alone there. A cache made from a stream with a preview track keeps nothing of the provider's
pictures. VLC plays and the streaming sites' own players have no previews.

The page reads `GET /api/stream/sessions/<id>/previews` once the session loads, and again whenever
the session or the answer to a position report carries a higher `preview_rev`, so new sheets show
on the open page without a reload. It never asks that route on a timer, and fetches a sheet only
when the pointer comes near a frame of it. `NOTESD_STREAM_PREVIEWS=off` starts no build, and the
route answers no frame.

```

```js
/** GET /api/stream/sessions/:id/previews: D1 lists the frames of its own preview track, through the pass-through; T1 has none. */
function previews(id) {
  if (id !== 'D1') return { state: 'none', rev: 0, source: null, cues: [] };
  const url = '/api/stream/sessions/D1/p?u=' + encodeURIComponent(SHEET) + '&img=1';
  const cues = [];
  for (let k = 0; k * PREVIEW_EVERY_S < FILM_S; k++) {
    cues.push({ start_s: k * PREVIEW_EVERY_S, end_s: Math.min((k + 1) * PREVIEW_EVERY_S, FILM_S), url, x: k * PREVIEW_W, y: 0, w: PREVIEW_W, h: PREVIEW_H });
  }
  return { state: 'ready', rev: 1, source: 'provider', cues };
}

/** Every address of a playlist comes back through the pass-through, as the daemon rewrites it. */
function playlist(file, id) {
  const dir = path.dirname(path.relative(HLS, file));
  return readFileSync(file, 'utf8')
    .split('\n')
    .map((line) => (line === '' || line.startsWith('#') ? line : '/api/stream/sessions/' + id + '/p?u=' + encodeURIComponent(path.posix.join(dir, line))))
    .join('\n');
}

/** The daemon's stream routes for sessions D1 (a cloud stream) and T1 (a torrent), answered from the film on disk. */
async function fakeDaemon(page) {
  const film = readFileSync(FILM);
  const cut = Math.floor(film.length * ON_DISK);
  const state = { released: false };
  await page.route('**/api/stream/sessions/**', async (route) => {
    const req = route.request();
    const url = new URL(req.url());
    const m = /^\/api\/stream\/sessions\/(D1|T1)(?:\/(p|previews))?$/.exec(url.pathname);
    if (!m) return route.fulfill({ status: 404, json: { error: 'not_found' } });
    if (m[2] === 'previews') return route.fulfill({ json: previews(m[1]) });
    if (m[2] === 'p') {
      const file = path.join(HLS, url.searchParams.get('u') ?? '');
      const ext = path.extname(file);
      const headers = { 'x-notesd-upstream': '200' };
      if (ext === '.m3u8') return route.fulfill({ status: 200, headers, contentType: TYPES[ext], body: playlist(file, m[1]) });
      return route.fulfill({ status: 200, headers, contentType: TYPES[ext] ?? 'application/octet-stream', body: readFileSync(file) });
    }
    if (req.method() === 'GET') return route.fulfill({ json: session(m[1]) });
    return route.fulfill({ status: 404, json: { error: 'not_found' } });
  });
  await page.route('**/api/stream/torrent/**', async (route) => {
    const req = route.request();
    const m = /^\/api\/stream\/torrent\/([0-9a-f]{40})(\/map|\/f\/0)?$/.exec(new URL(req.url()).pathname);
    if (!m) return route.fulfill({ status: 404, json: { error: 'not_found' } });
    if (m[2] === undefined) return route.fulfill({ json: { info_hash: m[1], state: 'downloading', peers: 23, down_kbps: 25600, up_kbps: 800, progress: ON_DISK } });
    if (m[2] === '/map') return route.fulfill({ json: { duration_s: 52, ranges: [[0, 52 * ON_DISK]] } });
    const asked = /bytes=(\d+)-(\d*)/.exec(req.headers()['range'] ?? '');
    const start = asked ? Number(asked[1]) : 0;
    let end = asked && asked[2] !== '' ? Math.min(Number(asked[2]), film.length - 1) : film.length - 1;
    if (start >= cut) {
      // Not on disk yet: the answer waits for its pieces, as the daemon's file route does.
      while (!state.released) await new Promise((r) => setTimeout(r, 200));
      return route.abort().catch(() => {});
    }
    end = Math.min(end, cut - 1);
    await route
      .fulfill({ status: 206, headers: { 'content-type': 'video/mp4', 'accept-ranges': 'bytes', 'content-range': 'bytes ' + start + '-' + end + '/' + film.length }, body: film.subarray(start, end + 1) })
      .catch(() => {});
  });
  return state;
}
```

### Step 6: The fixture film for the end-to-end proof
**File:** `.claude/skills/verify-notesd/scripts/stream/make-preview-film.sh` (new; `chmod +x`)
**Change:** a 600 s film whose picture gives away its time: a white bar 48 px wide crosses a dark
picture from left to right over the whole film, so two frames 10 s apart differ by a few pixels and
two frames 300 s apart share nothing. The same frames go into `film.mp4` (the torrent's file: H.264
and AAC tagged English, faststart, so Chrome plays it as is with no remux) and into `hls/` (copied,

### Step 7: The end-to-end steps
**File:** `.claude/skills/verify-notesd/scripts/stream/seek-previews.steps.mjs` (new)
**Change:** one steps file, two journeys on one run (`PREVIEW_ONLY=cache` or `torrent` runs one).
Each plays the film in the real page, waits until `window.notesdStream.previews` is `ready` and
`local` (which also proves the page took the frames without a reload: R1.5's path end to end),
rests the pointer on the timeline at 125 s (first sheet) and 487 s (second sheet), screenshots the
frame element the page shows, and judges it with ffmpeg:

- the reference: `film.mp4` decoded once at one frame every 2 s, each scaled to 128×72 grey;
- the frame shown, scaled the same way;
- **match:** the reference frame most like the one shown (lowest mean absolute difference) is within
  one preview interval (the covering cue's `end_s - start_s`) plus the 2 s grid of the time the box
  shows;
- **control:** the frame of the time half the film away is at least 3 times as far (and at least 8
  grey levels) from the one shown as the closest frame within that interval. A page showing a frame
  of the wrong time, a blank box or the same frame everywhere fails one of the two.

**Code:**
```js
// Seek previews end to end (seek-preview-thumbnails phase 5): on a throwaway daemon with torrents on, the real
// page plays a film from the stream cache and a film from a torrent; the daemon makes their preview sheets with
// this machine's ffmpeg; the pointer rests on the timeline; the frame the page shows must be ffmpeg's frame of
// that time (within one preview interval), and the frame of a far-away time must not match it.
//   FIX=$(bash .claude/skills/verify-notesd/scripts/stream/make-preview-film.sh "$HOME/.local/state/notesd-verify/.preview-film")
//   NOTESD_STREAM_PREVIEWS=on TORRENT_FIXTURE_FILE="$FIX/film.mp4" verify.sh up --web --torrent   (note RUN and DIRECT=)
//   DIRECT=<that path> PREVIEW_FILM="$FIX" verify.sh ui RUN .claude/skills/verify-notesd/scripts/stream/seek-previews.steps.mjs
// PREVIEW_ONLY=cache or PREVIEW_ONLY=torrent runs one of the two journeys. Chromium here, never the owner's
// streaming Chrome; the stream host is the fixture host and the swarm the loopback seeder.
// Logs "SEEK PREVIEW CACHE 125 PASS", "SEEK PREVIEW CACHE 487 PASS", "SEEK PREVIEW TORRENT 125 PASS" and
// "SEEK PREVIEW TORRENT 487 PASS", each with the distances it judged; the first failed check throws.
import { spawnSync } from 'node:child_process'
import { existsSync, symlinkSync, writeFileSync } from 'node:fs'
import path from 'node:path'

const DIRECT = process.env.DIRECT
const FIX = process.env.PREVIEW_FILM
const ONLY = process.env.PREVIEW_ONLY ?? ''
/** The size every picture is compared at, grey. */
const W = 128
const H = 72
const PX = W * H
/** The reference frames are ffmpeg's, one every GRID_S seconds of the film. */
const GRID_S = 2
/** Where the pointer rests: one time in each of the film's two sheets (0-360 s, 360-600 s). */
const AT = [125, 487]
/** How far the time the box shows may be from the time the pointer was put at (the thumb's inset, a pixel's worth). */
const POINTER_SLACK_S = 5

function check(ok, what) {
  if (!ok) throw new Error(what)
}

async function until(page, cond, ms, what) {
  for (let waited = 0; waited < ms; waited += 1000) {
    if (await cond()) return
    await page.waitForTimeout(1000)
  }
  check(await cond(), what)
}

/** ffmpeg's output as W×H grey pictures, one after another. */
function grey(inputArgs, filters, input) {
  const vf = [...filters, `scale=${W}:${H}:flags=area`, 'format=gray'].join(',')
  const res = spawnSync('ffmpeg', ['-hide_banner', '-loglevel', 'error', '-nostdin', ...inputArgs, '-vf', vf, '-f', 'rawvideo', 'pipe:1'], {
    input,
    maxBuffer: 256 * 1024 * 1024,
  })
  check(res.status === 0, `ffmpeg failed: ${String(res.stderr ?? res.error)}`)
  return res.stdout
}

/** The film's own frames: frames[k] is the frame at k·GRID_S seconds. */
function filmFrames(film) {
  const raw = grey(['-i', film], [`fps=1/${GRID_S}`])
  const frames = []
  for (let at = 0; at + PX <= raw.length; at += PX) frames.push(raw.subarray(at, at + PX))
  return frames
}

/** A PNG screenshot as one W×H grey picture. */
const pictureOf = (png) => grey(['-i', 'pipe:0'], [], png).subarray(0, PX)

/** Mean absolute difference of two grey pictures, 0 to 255. */
function mad(a, b) {
  let sum = 0
  for (let i = 0; i < PX; i++) sum += Math.abs(a[i] - b[i])
  return sum / PX
}

/** "2:05" or "1:02:05" to seconds. */
function seconds(text) {
  const parts = text.trim().split(':').map(Number)
  check(parts.length >= 2 && parts.every(Number.isFinite), `the box's time reads "${text}"`)
  return parts.reduce((s, p) => s * 60 + p, 0)
}

/** Rests the pointer on the timeline at `t` and returns the time the box shows and a screenshot of its frame. */
async function hoverAt(page, t, duration) {
  const seek = await page.locator('.st-seek').boundingBox()
  check(seek !== null, 'the timeline is not on the page')
  const x = seek.x + (seek.width * t) / duration
  const y = seek.y + seek.height / 2
  await page.mouse.move(x - 40, y - 80)
  await page.mouse.move(x, y, { steps: 6 })
  const frame = page.locator('.st-preview .st-preview-frame')
  for (let waited = 0; !(await frame.isVisible()); waited += 400) {
    check(waited < 8_000, `no frame shows over the timeline at ${t} s (the box: "${await page.locator('.st-preview').innerText().catch(() => 'none')}")`)
    // The controls hide 2.5 s after the mouse last moved, and the box with them: a pixel's move keeps them up.
    await page.mouse.move(x + ((waited / 400) % 2), y)
    await page.waitForTimeout(400)
  }
  await page.waitForTimeout(250)
  const shown = seconds(await page.locator('.st-preview .st-preview-time').innerText())
  const png = await frame.screenshot()
  return { shown, png }
}

/** The frame on screen against ffmpeg's frames: the closest must be within one interval of `shown`, the far one must not match. */
function judge(label, frames, cues, duration, shown, png) {
  // The page's own list (phase 4's Previews): its cues are { startS, endS, url, x, y, w, h }.
  const cue = cues.find((c) => c.startS <= shown && shown < c.endS)
  check(cue !== undefined, `${label}: the session's previews hold no frame for ${shown} s`)
  const interval = cue.endS - cue.startS
  const pic = pictureOf(png)
  const dist = frames.map((f) => mad(pic, f))
  let best = 0
  for (let k = 1; k < dist.length; k++) if (dist[k] < dist[best]) best = k
  const bestS = best * GRID_S
  const near = Math.min(...dist.filter((_, k) => Math.abs(k * GRID_S - shown) <= interval + GRID_S))
  const farS = (shown + duration / 2) % duration
  const far = dist[Math.min(Math.round(farS / GRID_S), dist.length - 1)]
  check(
    Math.abs(bestS - shown) <= interval + GRID_S,
    `${label}: the frame shown at ${shown} s looks most like ${bestS} s of the film (difference ${dist[best].toFixed(1)}), more than ${interval} s away`,
  )
  check(
    far >= 3 * Math.max(near, 1) && far >= 8,
    `${label}: the control failed: the frame of ${Math.round(farS)} s (difference ${far.toFixed(1)}) is about as close as the frame of ${shown} s (${near.toFixed(1)})`,
  )
  return `closest ${bestS} s (difference ${dist[best].toFixed(1)}), within ${interval} s; control ${Math.round(farS)} s at ${far.toFixed(1)}`
}

/** Opens the session's page, waits for its whole previews from this machine, and judges two hovers. */
async function watch(page, base, sid, label, frames, shot, log, torrent) {

  await page.waitForFunction(() => window.notesdStream?.stage === 'ready', null, { timeout: 60_000 })
  await page.waitForFunction(() => {
    const v = document.querySelector('video')
    return !!v && !v.paused && v.currentTime > 2
```
