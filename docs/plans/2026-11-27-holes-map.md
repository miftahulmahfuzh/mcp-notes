## 7. Limitations in architecture.md that could now be lifted

- **"Text needs the network. Notes live in Neon … a spent transfer quota pauses the database for
  30 minutes."** Stale since 2026-11-18: notes live on the local Docker Postgres. This is a guide
  fix, left to the guides-vs-code sibling worker (this change does not edit guides). It also
  makes `src/db/quota.ts` and `meter.ts` candidates for removal after the import.
- **"The session graph refreshes by polling"** (30 s backing off to 2 min) and the 5-minute
  notes poll. These cadences were chosen to cut Neon egress (neon-egress-reduction, 2026-11-08).
  On a local database the graph could get an SSE stream like notes, and the notes poll could
  slow down or stop. 1 phase.
- **"Edits made by a second daemon on the same Postgres are not instant."** `LISTEN/NOTIFY` on the
  shared Postgres would make them instant. It only matters for two daemons on one database, so
  it is low priority.
- **"Pasted images are kept … never deleted."** Stored by sha256 under `chat-images/`. A sweep of
  the files that no chat message or note refers to is now cheap on a local database. Low priority.
- Still true, keep: local-only photos, single user, WSL, desktop first, HEIC colour, loose tags,
  resume needs tmux, movies play where the file is.
